## 🎯 功能特性

### 1. 关联对象选择
跟进记录现在支持三种关联对象：
- **线索**（Lead）：尚未转化为商机的潜在客户
- **商机**（Opportunity）：已转化的商业机会，正在推进中
- **客户**（Customer）：已签约或预备签约的客户

### 2. 表单智能联动
- 选择商机 → 自动带出对应客户
- 选择客户 → 自动带出对应商机（如果有）
- 选择客户 → 商机下拉仅显示该客户的商机

### 3. 权限控制
- admin 可以看到所有线索/商机/客户
- sales 只能看到自己负责的线索/商机/客户
- 跟进记录的可见性遵循关联对象的权限规则

### 4. UI/UX 优化
- **分组布局**：关联对象集中展示，逻辑清晰
- **说明文字**：每个选项都有简短说明，新用户易理解
- **视觉分隔**：使用边框、背景色、分割线区分不同部分
- **可点击链接**：列表页的关联对象可点击跳转

## 📊 数据流程

### 跟进记录的三种使用场景

#### 场景 1：线索阶段的跟进
```
线索池 → 分配给销售 → 销售联系跟进 → 记录跟进信息（关联线索）
```
- 在线索列表页直接"写跟进"
- 或在跟进记录页"新建跟进"并选择线索

#### 场景 2：商机阶段的跟进
```
线索转商机 → 商机推进 → 记录跟进信息（关联商机+客户）
```
- 在商机列表页直接"写跟进"
- 或在跟进记录页"新建跟进"并选择商机

#### 场景 3：客户阶段的跟进
```
商机转客户 → 客户维护 → 记录跟进信息（关联客户）
```
- 在客户列表页直接"写跟进"
- 或在跟进记录页"新建跟进"并选择客户

### 独立新建跟进记录
用户也可以从"跟进记录"菜单进入，手动选择要关联的线索/商机/客户，适用于：
- 批量整理跟进记录
- 补充历史跟进信息
- 跨阶段查看完整跟进历史

## 📋 表单字段说明

### 必填字段
- **跟进内容**：跟进的详细描述（必填）
- **跟进日期**：跟进发生的日期（必填，默认今天）
- **关联对象**：至少选择线索、商机、客户之一（系统提示，但不强制）

### 可选字段
- **沟通对象**：本次跟进沟通的对方联系人（如：张经理）
- **一句话进展**：简短总结本次跟进的结果（如：客户表示有兴趣）
- **下一步计划**：后续要做的事情（如：下周一发送产品方案）
- **客户需求**：本次跟进了解到的客户需求（如：需要支持自定义配置）

### 关联对象选择
- **关联线索**：选择此跟进记录关联的线索（早期阶段）
- **关联商机**：选择此跟进记录关联的商机（推进阶段）
- **关联客户**：选择此跟进记录关联的客户（签约阶段）

## 💡 使用建议

### 1. 线索阶段
- 主要使用"关联线索"
- 记录首次联系、需求挖掘、意向确认等
- 不建议同时关联商机/客户（不同阶段）

### 2. 商机阶段
- 主要使用"关联商机"
- 系统会自动关联对应的客户
- 记录方案讨论、报价、谈判进展等

### 3. 客户阶段
- 主要使用"关联客户"
- 记录售后服务、需求变更、续约跟进等
- 如果客户有多个商机，可以单独选择具体商机

### 4. 独立跟进
- 如果跟进与具体对象无关，可以不选择关联
- 但建议至少关联一个，便于后续筛选和统计
- 可以关联多个对象（如：商机+客户）
