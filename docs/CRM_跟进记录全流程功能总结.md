## 🎯 功能特性

### 1. 全流程覆盖
- **线索阶段**：分配销售 → 状态变更 → 手动跟进
- **商机阶段**：状态变更 → 手动跟进
- **客户阶段**：状态变更 → 手动跟进

### 2. 默认内容 + 可追加
- 所有状态变更都有默认的跟进内容
- 销售人员可以保留默认内容，也可以追加详细说明
- 即使不写补充说明，也会记录默认的状态变更

### 3. 跟进历史可见性
- 当线索/商机/客户更换负责人时，新销售人员能看到之前所有的跟进记录
- 每条跟进记录都标注了跟进人姓名和时间
- 区分系统自动生成（状态变更）和手动添加的跟进

### 4. 权限控制
- **admin（销售主管）**：
  - 可查看所有线索/商机/客户的所有跟进记录
  - 可编辑/删除任何跟进记录（功能入口已预留）
  
- **sales（销售人员）**：
  - 只能查看自己负责的线索/商机/客户的跟进记录
  - 可以看到该记录上所有历史销售人员留下的跟进
  - 只能新增跟进，不能编辑/删除

### 5. 时间线全流程
- **按商机查**：该商机的跟进时间线包含**该商机关联线索的跟进**（线索 + 商机一条线）
- **按客户查**：该客户的跟进时间线包含**来源商机 + 关联线索的跟进**（线索 + 商机 + 客户全流程）

### 6. UI/UX 优化
- **多行同时展开**：线索/商机/客户表均可同时展开多条记录的时间线，互不影响
- **提交跟进后**：该行保持展开，时间线自动刷新显示最新一条，无需整页刷新
- **展开/收起时间线**：默认显示最近一条，点击展开查看全部
- **写跟进按钮**：随时可以添加跟进，不依赖状态变更
- **状态变更弹窗**：强制填写（允许只提交默认内容）
- **区分显示**：系统生成的跟进用蓝色背景标识

## 🧪 测试建议

### 1. 线索流程测试
1. **创建线索**
   - 进入"线索管理表" → "新建线索"
   
2. **分配销售人员**（admin 权限）
   - 选择销售人员下拉
   - 弹窗显示默认内容："线索已分配给 XXX"
   - 可追加说明，点击确认
   - 展开时间线，查看跟进记录

3. **更换销售人员**（admin 权限）
   - 再次选择其他销售人员
   - 弹窗显示："负责人由 XXX 变更为 YYY"
   - 切换到新销售人员账号，确认能看到旧的跟进记录

4. **修改线索状态**
   - 选择状态："未跟进" → "跟进中"
   - 弹窗显示默认内容："状态由「未跟进」变更为「跟进中」"
   - 追加详细说明（或直接提交默认内容）
   - 展开时间线，确认记录已添加

5. **手动写跟进**
   - 点击"写跟进"按钮
   - 填写跟进内容（必填）
   - 可选填：沟通对象、一句话进展、下一步、客户需求
   - 提交后展开时间线查看

6. **转入商机**
   - 状态改为"有意向" → **系统自动生成一条商机**并出现在商机表
   - 点击该行「编辑/补全商机」→ 跳转商机表并高亮该商机
   - 在商机表内**直接点击单元格**行内编辑补全（产品类型、金额等）

### 2. 商机流程测试
1. **商机列表**
   - 进入"商机管理表"
   - 展开任一商机查看跟进时间线

2. **修改商机状态**
   - 选择状态："初步沟通" → "方案确认"
   - 弹窗填写跟进说明
   - 展开时间线确认记录

3. **手动写跟进**
   - 点击"写跟进"按钮
   - 填写内容并提交

4. **转入客户**
   - 状态改为"待签约"或"已赢单"
   - 系统自动创建客户记录

### 3. 客户流程测试
1. **客户列表**
   - 进入"客户管理表"
   - 展开任一客户查看跟进时间线

2. **修改客户状态**
   - 选择状态："预备签约" → "已签约"
   - 弹窗填写跟进说明

3. **手动写跟进**
   - 点击"写跟进"按钮
   - 填写内容并提交

### 4. 权限测试

   - 确认可指定/变更线索销售人员；可删除任意线索（级联删商机与客户）

## 📝 注意事项

1. **数据库已更新**：已通过 `db:push` 更新，现有跟进记录会自动添加新字段的默认值

2. **依赖项**：已移除 `date-fns` 依赖，使用原生 JavaScript 日期格式化

3. **页面刷新**：写跟进提交后该行保持展开并仅刷新时间线；状态变更等仍会触发列表刷新

4. **默认内容**：所有状态变更都会生成默认的跟进内容，确保有记录可查

5. **权限验证**：所有 Action 都包含权限检查，确保数据安全
