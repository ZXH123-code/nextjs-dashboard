# CRM 飞书多维表格配置指南

> 本文档说明如何在飞书多维表格中配置与 Next.js CRM 项目一致的表结构和关联关系。  
> 业务逻辑和表单用法见 [CRM_四张表与表单逻辑说明.md](./CRM_四张表与表单逻辑说明.md)，技术细节见 [CRM_表结构与关系说明.md](./CRM_表结构与关系说明.md)。

## 一、四张表的关系与流转逻辑

```
线索管理 ──(状态=有意向)──> 商机管理 ──(状态=待签约/已赢单)──> 客户管理
    │                            │                              │
    └────────────────────────────┴──────────────────────────────┴──> 跟进记录（关联客户或商机）
```

**核心规则：**

- 线索状态选「有意向」→ 自动创建商机，并同步：客户名称、城市、销售人员
- 商机状态选「待签约」或「已赢单」→ 自动创建客户，并同步：**来源线索的客户名称** → 客户名称、昵称/城市/客户分层/行业、销售人员（与商机名称无关）
- 跟进记录通过「关联记录」字段绑定客户或商机

## 二、飞书多维表格字段关联配置（详细步骤）

### 1. 线索管理表

| 字段名       | 类型      | 说明                                        |
| ------------ | --------- | ------------------------------------------- |
| 客户名称     | 文本      | 必填                                        |
| 昵称         | 文本      | 选填                                        |
| 城市         | 单选/文本 |                                             |
| 详细地址     | 文本      |                                             |
| 行业         | 单选/文本 |                                             |
| 线索来源     | 单选      | 如：展会、转介绍、官网                      |
| 线索创建日期 | 创建时间  | **自动生成**，字段类型选「创建时间」        |
| 客户分层     | 单选      | 如：A/B/C                                   |
| 销售人员     | 人员      | 关联成员，领取后自动更新                    |
| 企业标签     | 多选/文本 |                                             |
| 人员规模     | 单选/文本 |                                             |
| 状态         | 单选      | **关键**：未跟进 / 跟进中 / 有意向 / 无意向 |
| 是否领取     | 复选框    |                                             |
| **关联商机** | 关联记录  | 见下方配置                                  |

**「关联商机」字段配置：**

- 字段类型：**关联记录**
- 关联到：**商机管理**
- 关联方式：**单向关联**（线索 → 商机）
- 显示字段：商机名称
- 说明：当线索状态变为「有意向」时，在此表新建一条商机记录，此字段会自动指向新商机（需配合自动化）

- 字段类型：**关联记录**

**「关联客户」字段配置：**

- 字段类型：**关联记录**
- 关联到：**客户管理**
- 关联方式：**双向关联**
- 显示字段：客户名称

- 字段类型：**关联记录**
- 关联到：**客户管理**
- 关联方式：**单向引用**（跟进记录 → 客户）

- 显示字段：商机名称

## 三、关联方式总结表

| 主表     | 关联字段 | 被关联表 | 关联方式                | 说明                         |
| -------- | -------- | -------- | ----------------------- | ---------------------------- |
| 线索管理 | 关联商机 | 商机管理 | **单向**（线索 → 商机） | 线索转商机后，线索指向新商机 |
| 商机管理 | 关联线索 | 线索管理 | **单向引用**            | 商机记录来源线索             |
| 商机管理 | 关联客户 | 客户管理 | **双向**                | 商机赢单后与客户互相关联     |
| 客户管理 | 关联商机 | 商机管理 | **双向**                | 与上一条互为反向             |
| 商机管理 | 跟进记录 | 跟进记录 | **双向**                | 一个商机多条跟进             |
| 客户管理 | 跟进记录 | 跟进记录 | **双向**                | 一个客户多条跟进             |
| 跟进记录 | 关联客户 | 客户管理 | **单向引用**            | 跟进归属客户                 |
| 跟进记录 | 关联商机 | 商机管理 | **单向引用**            | 跟进归属商机                 |

## 四、飞书自动化配置（实现自动流转）

### 自动化 1：线索 → 商机

1. 进入「线索管理」表 → 右上角「自动化」
2. 新建自动化，触发条件：**当「状态」字段更改为「有意向」**
3. 动作：**在「商机管理」表中添加记录**
   - 商机名称：插入「当前记录」的「客户名称」
   - 城市：插入「当前记录」的「城市」
   - 销售人员：插入「当前记录」的「销售人员」
   - 创建日期：自动（创建时间字段）
   - 关联线索：插入「当前记录」（即本线索）
4. 可选：再添加动作「更新当前记录」→ 将「关联商机」设为刚创建的商机

### 自动化 2：商机 → 客户

1. 进入「商机管理」表 → 自动化
2. 新建自动化，触发条件：**当「状态」字段更改为「待签约」或「已赢单」**
3. 动作：**在「客户管理」表中添加记录**
   - 客户名称：插入「当前记录」的「关联线索」的「客户名称」（与商机名称无关，继承线索的客户名称）
   - 城市：插入「当前记录」的「关联线索」的「城市」（或当前记录的「城市」）
   - 销售人员：插入「当前记录」的「销售人员」
   - 关联商机：插入「当前记录」
4. 可选：更新商机记录的「关联客户」为新建的客户

## 五、权限配置（需付费版高级权限）

1. 进入多维表格 → 右上角「分享」→「权限管理」
2. 所有者开启「高级权限」
3. 设置角色：

   - **部门级（黄部长）**：可查看/编辑所有表，管理总池子
   - **销售人员 A/B/C**：行级权限，仅可查看/编辑「销售人员」= 自己的记录

4. 行级权限规则示例：
   - 线索管理：仅当「销售人员」包含当前用户时可见
   - 商机管理：同上
   - 客户管理：同上
   - 跟进记录：仅当「跟进人」= 当前用户 或 关联客户的「销售人员」= 当前用户时可见
