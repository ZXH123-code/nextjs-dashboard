# 高级筛选功能使用指南

## 功能概览

新版筛选系统支持:
1. ✅ **更多字段**: 支持数据库表中几乎所有有意义的字段
2. ✅ **"或"逻辑**: 支持多个条件组，组与组之间是"或"关系
3. ✅ **简洁直观**: 清晰的视觉标识（"且"/"或"标签），易于理解

## 筛选逻辑

### 条件组内（"且"关系）
同一个条件组内的所有条件必须**同时满足**。

**示例**: 
- 条件组1:
  - 城市 = "上海" **且**
  - 状态 = "跟进中"
  
→ 结果: 只显示城市是上海**并且**状态是跟进中的记录

### 条件组间（"或"关系）
多个条件组之间是**任意满足一个即可**。

**示例**:
- 条件组1: 城市 = "上海" **且** 状态 = "跟进中"
- **或**
- 条件组2: 城市 = "北京" **且** 状态 = "有意向"

→ 结果: 显示(上海的跟进中记录) **或者** (北京的有意向记录)

## 使用示例

### 示例 1: 简单筛选
**需求**: 找出所有上海的跟进中线索

**操作**:
1. 点击"筛选"按钮
2. 添加条件: 城市 = 上海
3. 添加条件: 状态 = 跟进中
4. 点击"应用筛选"

### 示例 2: "或"逻辑筛选
**需求**: 找出(上海的跟进中线索) 或者 (北京的有意向线索)

**操作**:
1. 点击"筛选"按钮
2. 在条件组1中:
   - 添加条件: 城市 = 上海
   - 添加条件: 状态 = 跟进中
3. 点击"添加条件组（或）"
4. 在条件组2中:
   - 添加条件: 城市 = 北京
   - 添加条件: 状态 = 有意向
5. 点击"应用筛选"

### 示例 3: 复杂筛选
**需求**: 找出所有重点关注的高价值客户

**操作**:
1. 点击"筛选"按钮
2. 添加条件: 重点关注 = 是
3. 添加条件: 实际成交金额 > 100000
4. 点击"应用筛选"

### 示例 4: 时间范围筛选
**需求**: 找出2024年1月之后创建的客户

**操作**:
1. 点击"筛选"按钮
2. 添加条件: 创建时间 >= 2024-01-01
3. 点击"应用筛选"

### 示例 5: 多销售筛选
**需求**: 找出销售A或销售B负责的所有线索

**操作**:
1. 点击"筛选"按钮
2. 在条件组1中:
   - 添加条件: 销售人员 包含 "张三"
3. 点击"添加条件组（或）"
4. 在条件组2中:
   - 添加条件: 销售人员 包含 "李四"
5. 点击"应用筛选"

## UI 说明

### 视觉标识
- **"且"标签**: 蓝色背景，表示条件组内的多个条件是"且"关系
- **"或"标签**: 橙色背景，表示条件组之间是"或"关系
- **虚线分隔**: 条件组之间用虚线分隔，更清晰

### 操作按钮
- **添加条件**: 在当前条件组内添加新条件
- **添加条件组（或）**: 添加新的条件组，实现"或"逻辑
- **删除图标**: 删除单个条件或整个条件组
- **清除全部**: 清空所有筛选条件
- **应用筛选**: 执行筛选并关闭对话框

## 技术实现

### 数据结构
```typescript
// 单个条件
type FilterCondition = {
  id: string;
  field: string;
  operator: string;
  value: string | string[];
};

// 条件组（组内是"且"）
type FilterGroup = {
  id: string;
  conditions: FilterCondition[];
};
```

### 筛选逻辑
```typescript
// 多组"或"逻辑
data.filter(item => 
  groups.some(group =>        // 至少有一组匹配（或）
    group.conditions.every(   // 组内所有条件都匹配（且）
      condition => checkCondition(item, condition)
    )
  )
)
```

## 兼容性

新版筛选系统完全向后兼容:
- ✅ 如果只有一个条件组，行为与旧版相同
- ✅ 旧的筛选条件会自动转换为单个条件组
- ✅ API 接口保持兼容

## 最佳实践

1. **简单筛选**: 对于简单需求，使用单个条件组即可
2. **复杂筛选**: 需要"或"逻辑时，使用多个条件组
3. **性能**: 筛选在前端执行，对于大数据量建议后端分页
4. **保存**: 筛选条件在会话期间保留，刷新页面后会重置

## 常见问题

### Q: 如何实现"A或B"的简单筛选？
A: 创建两个条件组，每组一个条件，分别是A和B。

### Q: 可以混合使用"且"和"或"吗？
A: 可以！每个条件组内用"且"，条件组之间用"或"。

### Q: 如何筛选空值？
A: 使用"为空"或"不为空"操作符，不需要输入值。

### Q: 日期格式是什么？
A: YYYY-MM-DD 格式，例如 2024-01-01。

### Q: 能否保存常用的筛选条件？
A: 当前版本筛选条件在会话期间保留，未来可考虑添加保存功能。
