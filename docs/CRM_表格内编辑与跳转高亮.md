# CRM 表格内编辑与跳转高亮

> 本文档说明线索表、商机表、客户表的 Excel 风格行内编辑，表格通用样式（居中、截断、查看完整值），以及表与表之间的「查看并高亮」跳转逻辑。

---

## 〇、表格通用样式与界面

- **所有表格**（线索、商机、客户、跟进记录）：表头与单元格内容**水平居中**；内容过长时**截断显示**，悬停（`title`）可看**完整值**。
- **跟进记录表**：每条记录支持「**查看**」按钮，点击弹出对话框显示该条记录的完整内容（不截断）。
- **顶部栏**：仪表盘顶部栏显示**当前登录用户名称**（优先显示姓名，否则邮箱，否则「用户」）。
- **线索表「流转阶段」列**：三格进度条（线索 → 商机 → 客户），带图标与当前/已完成/未完成状态；当已转入客户且**客户状态为「已签约」**时，「客户」一格显示为已完成（绿色勾），表示该线索在客户层面已成功签约。

## 一、商机表：Excel 风格行内编辑

### 可编辑字段

在商机管理表中，**直接点击单元格**即可编辑，失焦或按 Enter 保存，Esc 取消：

| 列       | 说明 |
|----------|------|
| 商机名称 | 文本 |
| 产品类型 | 文本 |
| 商机金额 | 数字 |
| 预计赢单日期 | 日期 |
| 销售人员 | 下拉（仅 admin 可改；销售为只读） |
| 交付负责人 | 下拉 |
| 状态     | 下拉（通过状态选择器，非行内） |

### 从线索表进入

- 线索表操作列：当该线索已有关联商机时，显示「**编辑/补全商机**」
- 点击后跳转到**商机管理表**，列表为**全部商机**（不筛单条），该商机行**高亮**并自动滚动到视区

---

## 二、线索表：Excel 风格行内编辑（仅管理员）

### 可编辑字段与查看记录

- **表内行内编辑**（管理员可编辑，销售只读）：客户名称、昵称、地址、城市、行业、线索来源、联系方式等；销售人员和状态通过下拉（LeadSalesPersonSelect、LeadStatusSelect）操作，所有角色可用。
- **查看记录**：操作列「更多」→「查看记录」打开**右侧滑层**，展示该条线索全部字段（含创建时间、客户等级等），支持行内编辑（与表内逻辑一致），无额外说明文案。

### 新建线索

- **仅管理员**可点击「新建线索」：新建一条空记录（客户名称「（待补全）」），在表内行内编辑补全
- **批量导入**：仅管理员可执行；销售可见「新建线索」「批量导入」入口，点击会提示「**权限不足**」

## 三、表与表之间的「查看并高亮」跳转

### 从线索表 → 商机表

- 线索行有关联商机时，操作列显示「编辑/补全商机」
- 点击 → 跳转 ` /dashboard/crm/opportunities?highlight={商机ID} `
- 商机表显示**全部商机**，该行高亮（蓝色脉冲）并自动滚动

### 从商机表 → 客户表 / 线索表

- **查看客户**：商机已流入客户时，操作列显示「**查看客户**」，点击跳转 ` /dashboard/crm/customers?highlight={客户ID} `，客户表高亮该客户行并滚动。
- **来源线索**：商机表「**来源线索**」列本身为可点击链接（带图标与线索名称），点击跳转 ` /dashboard/crm/leads?highlight={线索ID} `，线索表高亮该线索行并滚动。原「查看线索」按钮已合并进该列，不再单独显示。

### 高亮表现（三张表一致）

带 `?highlight=id` 进入页面时：

- 对应行**蓝色柔光脉冲**闪烁约 3 次（约 2.4 秒）后恢复，无需额外说明文案
- 自动展开该行（跟进时间线等）
- 滚动到该行到视区中央

## 四、客户表：Excel 风格行内编辑

- **可编辑字段**：客户名称、昵称、城市、客户分层、行业、初次维护日期。直接点击单元格即可编辑，失焦或按 Enter 保存，Esc 取消。
- **权限**：**管理员**可编辑全部客户；**销售人员**仅可编辑自己负责的客户（该客户行的 `salesPersonId` 为自己）。
- **跟进记录**：客户表已**无「跟进记录」按钮**，通过**展开该行**查看「跟进时间线」即可；全部跟进汇总在「跟进记录」页面。

## 五、展开与时间线行为

- **多行同时展开**：线索表、商机表、客户表均支持**同时展开多条记录**的跟进时间线（点击行首展开/收起，互不影响）。
- **提交跟进后**：在任意表内「写跟进」并提交后，**该行保持展开**，时间线自动刷新显示最新一条，无需整页刷新。

## 六、状态流转与自动流入（与编辑方式无关）

- **线索 → 商机**：线索状态改为「有意向」时，后端自动创建一条商机（名称默认为**「{客户名称}-商机」**，客户名为空时为「（待补全）-商机」，状态=初步沟通），可在商机表内行内编辑修改。
- **商机 → 客户**：商机状态改为「待签约」或「已赢单」时，后端自动创建一条客户并关联该商机。
