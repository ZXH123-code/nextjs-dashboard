# CRM 四张表与表单逻辑说明

> 写给用这个系统的人看的，把线索、商机、客户、跟进记录之间的关系和怎么用说清楚。

---

## 一、整体流程：一个客户是怎么来的

想象你在跑销售业务，大致是这样一条线：

```
线索（潜在客户） → 商机（在谈的单子） → 客户（签下来的）
                      ↑
                跟进记录（每次沟通都记一笔）
```

- **线索**：刚拿到联系方式，还没深入聊
- **商机**：聊过了，有意向，在推进
- **客户**：谈成了，签了约
- **跟进记录**：每次打电话、见面、发方案的记录，可挂在线索、商机或客户上；在商机/客户时间线中会**按全流程**展示（按商机查含关联线索跟进，按客户查含来源商机+关联线索跟进）

---

## 二、四张表各自干什么

### 1. 线索管理表

**干啥的**：存「可能成为客户」的人/公司，相当于一个大池子。

**典型来源**：展会、转介绍、官网留资、名单导入等。

**关键字段**：
- 客户名称、昵称、城市、行业、线索来源
- **状态**：未跟进 → 跟进中 → 有意向 / 无意向

**什么时候用**：拿到新线索就新建一条，后续在列表里改状态。**仅管理员**可「新建线索」（新建一条空记录）、「批量导入」及在表格内 Excel 风格行内编辑；销售可见入口，但点击会提示「权限不足」。

---

### 2. 商机管理表

**干啥的**：存「正在谈」的单子，有明确意向、在推进的。

**关键字段**：
- 商机名称、产品类型、商机金额、预计赢单日期、销售人员、交付负责人
- **状态**：初步沟通 → 方案确认 → 待签约 / 已赢单 / 已丢单

**什么时候用**：
- **线索状态改成「有意向」时，系统会自动生成一条商机**（商机名称默认为**「{客户名称}-商机」**，客户名称为空时为「（待补全）-商机」，状态=初步沟通），并出现在商机表中
- 补全商机信息：在线索表点「编辑/补全商机」会跳转到商机表并高亮该条；或在商机表内**直接点击单元格**进行 Excel 风格行内编辑（商机名称、产品类型、金额、预计赢单日期、销售人员、交付负责人、状态等）
- **无独立「新建商机」入口**：商机仅由「线索→有意向」自动流入，再在表内补全

---

### 3. 客户管理表

**干啥的**：存「已经签下来」的客户，要长期维护的。

**关键字段**：
- 客户名称、城市、客户分层、行业
- **状态**：预备签约 / 已签约 / 流失

**什么时候用**：
- **商机状态改成「待签约」或「已赢单」时，系统会自动生成一条客户**并关联该商机
- 也可以手动新建客户，比如老客户补录
- 从商机表点「查看客户」可跳转到客户表并**高亮**对应客户记录
- 客户表支持 **Excel 风格行内编辑**（客户名称、昵称、城市、客户分层、行业、初次维护日期）；管理员可编辑全部，销售仅可编辑自己负责的客户

---

### 4. 跟进记录表

**干啥的**：每次和客户/商机的沟通都记一笔，方便复盘和交接。

**关键字段**：
- 跟进内容、跟进日期、沟通对象
- 一句话进展、下一步、客户需求
- **关联客户**、**关联商机**、**关联线索**（至少选一个，方便筛选）

**什么时候用**：每次打电话、拜访、发方案后，新建一条跟进记录，挂在对应的线索、商机或客户上。**跟进记录页**汇总全部记录，支持按关联线索、商机、客户筛选；管理员看全部，销售人员只看自己负责的。

---

## 三、四张表之间的逻辑关系

### 线索 → 商机

| 触发方式 | 说明 |
|----------|------|
| **自动** | 在线索列表里把某条线索的「状态」改成「有意向」时，**系统自动创建一条商机**，并出现在商机表中 |

**会带过去什么**：商机名称默认为 **「{线索的客户名称}-商机」**（客户名为空时为「（待补全）-商机」），可在商机表内行内编辑修改；销售人员从线索带出。之后在商机表内行内编辑补全产品类型、金额等。

**操作入口**：线索表该行显示「编辑/补全商机」→ 点击跳转到商机表并高亮该商机，在表内直接点击单元格编辑即可。

---

### 商机 → 客户

| 触发方式 | 说明 |
|----------|------|
| **自动** | 在商机列表里把某条商机的「状态」改成「待签约」或「已赢单」时，**系统自动创建一条客户**并关联该商机 |

**会带过去什么**：**线索的客户名称** → 客户名称，及来源线索的昵称、城市、客户分层、行业等（与商机名称无关）。

**商机表**：
- **已流入客户**：操作列显示「查看客户」→ 点击跳转到客户表并**高亮**该客户记录
- **来源线索**：「来源线索」列本身为可点击链接，点击跳转到线索表并**高亮**该线索记录（原「查看线索」按钮已合并进该列）

---

### 跟进记录 → 客户 / 商机 / 线索

跟进记录通过「关联客户」「关联商机」或「关联线索」挂在某条客户、商机或线索上。

- 新建跟进时，可选关联客户、关联商机、关联线索（至少选一个，方便筛选）
- **联动**：选客户后，商机仅显示该客户的来源商机；选商机后，若已转入客户则自动带出客户
- **查看方式**：在线索表/商机表/客户表内**展开该行**即可看到「跟进时间线」；**跟进记录页**汇总全部跟进，支持按关联线索、商机、客户筛选；**管理员**看全部，**销售人员**只看自己负责的
- 客户表已**无「跟进记录」按钮**，统一通过展开行内时间线或跟进记录页查看

## 四、表单与表格内编辑

### 新建线索（仅管理员）

- **入口**：线索管理表 → 右上角「新建线索」（销售可见但点击提示「权限不足」）
- **逻辑**：管理员点击后**新建一条空记录**（客户名称暂为「（待补全）」），新行出现在线索表中，**在表格内直接点击单元格**进行 Excel 风格行内编辑补全（客户名称、昵称、城市、行业、线索来源等）
- **批量导入**：同上，仅管理员可执行；销售可见入口，点击提示「权限不足」

---

### 商机：无独立新建页，表内补全

- **商机来源**：仅由「线索状态改为有意向」自动生成一条商机
- **补全方式**：在**商机管理表**内直接**点击单元格**行内编辑（商机名称、产品类型、金额、预计赢单日期、销售人员、交付负责人、状态）
- **从线索进入**：线索表点「编辑/补全商机」→ 自动跳转商机表并**高亮**该商机行，即可在表内编辑

---

### 新建客户

- **入口**：客户管理表 → 右上角「新建客户」
- **必填**：客户名称
- **选填**：昵称、城市、客户分层、行业、人员规模、企业标签、主营产品、状态
- **提交后**：回到客户列表

---

### 新建跟进记录

- **入口**：跟进记录 → 右上角「新建跟进」
- **必填**：跟进内容、跟进日期
- **选填**：关联客户、关联商机、沟通对象、一句话进展、下一步、客户需求
- **建议**：至少选一个「关联客户」或「关联商机」，后面才好按客户/商机筛选
- **提交后**：自动跳转到跟进记录列表

**关联客户与商机的联动规则**：

| 操作 | 效果 |
|------|------|
| 先选客户 | 商机下拉框仅显示「该客户的来源商机」（即由该商机转入的客户，最多一条）；若客户为手动新建无来源商机，则商机仅显示「无」 |
| 先选商机 | 若该商机已转入客户，则客户自动选中；若商机尚未转入客户，则客户保持空 |
| 先选客户再选商机 | 商机只能选该客户对应的来源商机（或「无」） |
| 先选商机再选客户 | 客户自动带出；若改选其他客户，商机会自动更新为该客户的来源商机（或清空） |

## 五、状态流转一览

### 线索状态

```
未跟进 → 跟进中 → 有意向（自动生成商机，可表内补全）| 无意向
```

### 商机状态

```
初步沟通 → 方案确认 → 待签约 / 已赢单（自动转入客户）| 已丢单
```

### 客户状态

```
预备签约 | 已签约 | 流失
```

## 六、常见操作场景

| 场景 | 操作 |
|------|------|
| 拿到新线索 | 管理员：点「新建线索」出现空行，在表内编辑补全；或批量导入。销售：只能看到入口，点击提示权限不足 |
| 电话聊完觉得有戏 | 把线索状态改成「有意向」，**系统自动生成商机**并出现在商机表 |
| 补全商机信息 | 线索表点「编辑/补全商机」跳转商机表高亮该条，或在商机表内直接点击单元格编辑 |
| 方案发过去等签约 | 把商机状态改成「待签约」，**系统自动生成客户** |
| 合同签了 | 把商机状态改成「已赢单」，**系统自动生成客户** |
| 从商机去看客户/线索 | 商机表操作列：已转客户点「查看客户」→ 客户表高亮；未转点「查看线索」→ 线索表高亮 |
| 每次沟通后 | 在对应线索/商机/客户行点「写跟进」，或新建跟进记录并关联 |
| 想看某客户的沟通历史 | 在客户列表**展开该行**看跟进时间线，或在「跟进记录」页按客户筛选（客户表已无「跟进记录」按钮） |
