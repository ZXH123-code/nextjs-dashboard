# CRM 四张表与表单逻辑说明

> 写给用这个系统的人看的，把线索、商机、客户、跟进记录之间的关系和怎么用说清楚。

---

## 一、整体流程：一个客户是怎么来的

想象你在跑销售业务，大致是这样一条线：

```
线索（潜在客户） → 商机（在谈的单子） → 客户（签下来的）
                      ↑
                跟进记录（每次沟通都记一笔）
```

- **线索**：刚拿到联系方式，还没深入聊
- **商机**：聊过了，有意向，在推进
- **客户**：谈成了，签了约
- **跟进记录**：每次打电话、见面、发方案的记录，挂在客户或商机上

---

## 二、四张表各自干什么

### 1. 线索管理表

**干啥的**：存「可能成为客户」的人/公司，相当于一个大池子。

**典型来源**：展会、转介绍、官网留资、名单导入等。

**关键字段**：
- 客户名称、城市、行业、线索来源
- **状态**：未跟进 → 跟进中 → 有意向 / 无意向

**什么时候用**：拿到新线索就新建一条，后续在列表里改状态。

---

### 2. 商机管理表

**干啥的**：存「正在谈」的单子，有明确意向、在推进的。

**关键字段**：
- 商机名称、产品类型、商机金额
- **状态**：初步沟通 → 方案确认 → 待签约 / 已赢单 / 已丢单

**什么时候用**：
- 线索状态改成「有意向」后，到「新建商机」页选择该线索作为来源，完善商机信息后保存
- 也可以直接新建商机（不选线索），比如直接谈来的单子

---

### 3. 客户管理表

**干啥的**：存「已经签下来」的客户，要长期维护的。

**关键字段**：
- 客户名称、城市、客户分层、行业
- **状态**：预备签约 / 已签约 / 流失

**什么时候用**：
- 商机状态改成「待签约」或「已赢单」时，系统会自动生成一条客户
- 也可以手动新建客户，比如老客户补录

---

### 4. 跟进记录表

**干啥的**：每次和客户/商机的沟通都记一笔，方便复盘和交接。

**关键字段**：
- 跟进内容、跟进日期、沟通对象
- 一句话进展、下一步、客户需求
- **关联客户** 或 **关联商机**（至少选一个，方便筛选）

**什么时候用**：每次打电话、拜访、发方案后，新建一条跟进记录，挂在对应的客户或商机上。

---

## 三、四张表之间的逻辑关系

### 线索 → 商机

| 触发方式 | 说明 |
|----------|------|
| **自动** | 在线索列表里把某条线索的「状态」改成「有意向」 |
| **手动** | 状态已是「有意向」时，点「转入商机」按钮 |

**会带过去什么**：客户名称 → 商机名称、城市、销售人员。

---

### 商机 → 客户

| 触发方式 | 说明 |
|----------|------|
| **自动** | 在商机列表里把某条商机的「状态」改成「待签约」或「已赢单」 |
| **手动** | 状态已是「待签约」或「已赢单」时，点「转入客户」按钮 |

**会带过去什么**：商机名称 → 客户名称、城市、销售人员。

---

### 跟进记录 → 客户 / 商机

跟进记录通过「关联客户」或「关联商机」挂在某条客户或商机上。

- 新建跟进时，选一个客户或商机（也可以都选）
- **联动**：选客户后，商机仅显示该客户的来源商机；选商机后，若已转入客户则自动带出客户
- 在客户/商机详情或列表里，可以点「跟进记录」看该客户/商机的所有跟进

---

## 四、四个表单分别怎么用

### 新建线索

- **入口**：线索管理表 → 右上角「新建线索」
- **必填**：客户名称
- **选填**：昵称、城市、地址、行业、线索来源、客户分层、状态
- **提交后**：回到线索列表，新记录出现在最上面

---

### 新建商机

- **入口**：商机管理表 → 右上角「新建商机」
- **必填**：商机名称
- **选填**：关联线索（可从「有意向」且未转的线索里选）、产品类型、商机金额、状态
- **提交后**：回到商机列表

---

### 新建客户

- **入口**：客户管理表 → 右上角「新建客户」
- **必填**：客户名称
- **选填**：昵称、城市、客户分层、行业、人员规模、企业标签、主营产品、状态
- **提交后**：回到客户列表

---

### 新建跟进记录

- **入口**：跟进记录 → 右上角「新建跟进」
- **必填**：跟进内容、跟进日期
- **选填**：关联客户、关联商机、沟通对象、一句话进展、下一步、客户需求
- **建议**：至少选一个「关联客户」或「关联商机」，后面才好按客户/商机筛选
- **提交后**：自动跳转到跟进记录列表

**关联客户与商机的联动规则**：

| 操作 | 效果 |
|------|------|
| 先选客户 | 商机下拉框仅显示「该客户的来源商机」（即由该商机转入的客户，最多一条）；若客户为手动新建无来源商机，则商机仅显示「无」 |
| 先选商机 | 若该商机已转入客户，则客户自动选中；若商机尚未转入客户，则客户保持空 |
| 先选客户再选商机 | 商机只能选该客户对应的来源商机（或「无」） |
| 先选商机再选客户 | 客户自动带出；若改选其他客户，商机会自动更新为该客户的来源商机（或清空） |

## 五、状态流转一览

### 线索状态

```
未跟进 → 跟进中 → 有意向（可转商机）| 无意向
```

### 商机状态

```
初步沟通 → 方案确认 → 待签约 / 已赢单（可转客户）| 已丢单
```

### 客户状态

```
预备签约 | 已签约 | 流失
```

## 六、常见操作场景

| 场景 | 操作 |
|------|------|
| 拿到新线索 | 新建线索，状态选「未跟进」 |
| 电话聊完觉得有戏 | 把线索状态改成「有意向」，系统自动生成商机 |
| 方案发过去等签约 | 把商机状态改成「待签约」，系统自动生成客户 |
| 合同签了 | 把商机状态改成「已赢单」，系统自动生成客户 |
| 每次沟通后 | 新建跟进记录，关联到对应客户或商机 |
| 想看某客户的沟通历史 | 在客户列表点「跟进记录」，或去跟进记录页按客户筛选 |
